# Временные изменения на боевом сервере

Перед деплоем нового бота проверить локальные изменения в
`/opt/pravburo/bot_pravburo` на немецком сервере. Команды выполняет пользователь;
подключаться к серверу самостоятельно нельзя.

В старый бот вручную добавлена выдача чек-листа по
`?start=lawyerchecklist_thanks`:

- `tg_bot/app/handlers.py`: ключ `lawyerchecklist` в `DEEPLINK_BLOCKS`.
- `data/scenario.json`: блок `advertising_consultation_checklist`.
- `data/files/Что спросить у юриста на первой консультации.pdf`: загруженный PDF.

Перед обновлением сохранить изменения кода в Git stash. Проверить `git status`
и правила игнорирования: сценарий и PDF могут быть исключены из Git и тогда
обычный stash их не сохранит. Сделать отдельную резервную копию сценария и PDF
вне репозитория. Не использовать `stash -a`, чтобы не захватить `.env` и медиа.

После деплоя нового бота проверить выдачу чек-листа по той же ссылке. Старые
правки автоматически не накатывать: эта функция уже реализована в новой версии.
Удалить только созданный для этого переноса stash после успешной проверки.
